Flick Picker privacy notice

Flick Picker stores the profile name you enter and the movies and shows you mark as watched. This information is used only to generate recommendations.

Where data is stored

Your profile token is stored in Chrome extension storage. Profile names and viewing history are stored by the Flick Picker API. The project does not sell data, run advertising, or use browsing history.

Third-party data

The server may use The Movie Database (TMDB) for public movie and television metadata. Your profile and viewing history are not sent to TMDB.

Deletion

This demonstration does not yet include an account deletion interface. Do not enter sensitive information as a profile name. For project questions, use the repository at github.com/CamerenGreen/Flick-Picker.
